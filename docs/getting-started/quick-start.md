# Quick Start

MockOpenAI supports two modes depending on your test type.

For **unit and integration tests**, use the in-process mode — no server
process needed. See [In-Process Usage](../usage/in-process).

For **system and end-to-end tests** (Capybara, Playwright), use the
standalone server. See [Standalone Server](../usage/standalone).
